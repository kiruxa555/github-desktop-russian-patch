# Как помочь проекту

Сообщения о непереведённых надписях и предложения по переводу приветствуются.

В обращении укажите:

1. версию GitHub Desktop;
2. снимок экрана;
3. где находится надпись и как открыть это окно;
4. предлагаемый перевод, если он есть.

Не прикладывайте токены доступа, пароли, приватные ключи, резервные копии приложения или содержимое закрытых репозиториев.

Изменения словаря вносятся в `src/ru-map.cjs`. Перед Pull Request проверьте синтаксис файлов командой `node --check` и убедитесь, что патч не изменяет пользовательские данные репозиториев.
