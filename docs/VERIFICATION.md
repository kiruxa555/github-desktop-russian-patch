# Проверка русификатора 1.4.9

Дата проверки: 13 ноября 2026 года.

Окружение:

- GitHub Desktop 3.6.10 и 3.6.11;
- Windows PowerShell 5.1.

Результаты сборки:

- подготовлено 660 операций перевода;
- одни и те же 893 замены проходят по `main.js` и `renderer.js` обеих сборок;
- поле краткого текста коммита подписано «Заголовок коммита (обязательно)»; второе поле по-прежнему «Описание»;
- карточка опубликованной ветки: «Просмотр Pull Request из текущей ветки» и «Создание Pull Request из текущей ветки»; кнопки «Просмотреть Pull Request» и «Создать Pull Request»;
- заголовок списка веток «Recent branches» переведён как «Недавние ветки»;
- окно «О программе GitHub Desktop»: версия, проверка обновлений, бета-канал, условия и лицензия;
- пункт меню «Вид»: «Скрыть фильтр изменений» и «Показать фильтр изменений»;
- в дополнительных параметрах пояснение к Git Credential Manager начинается с «Используйте»;
- во внешнем виде: «Прочее», «Ширина табуляции (симв.)», «Всегда показывать список рабочих деревьев»;
- кнопка соавторов: «Добавить соавторов» и «Убрать соавторов»;
- меню параметров коммита: «Пропустить хуки коммита», «Добавить строку Signed-off-by», «Разрешить пустой коммит»;
- окно создания репозитория: «Создать новый репозиторий», «имя репозитория», «путь к репозиторию», «Создать файл README», «Файл .gitignore», «Лицензия», кнопка «Создать репозиторий»; пункт «None» в обоих списках показывается как «Нет», сами шаблоны .gitignore и названия лицензий остаются оригинальными;
- окно фильтра изменений: «Параметры фильтра», «Включённые в коммит», «Исключённые из коммита», «Новые файлы», «Изменённые файлы», «Удалённые файлы»;
- список веток: «Другие ветки» и кнопка «Выберите ветку для объединения с …»;
- параметры сравнения: «Пробелы», «Вид сравнения», «Единый вид», «Раздельный вид»;
- заголовок списка файлов в истории: «Изменено файлов: …»;
- предпросмотр Pull Request: «Открыть Pull Request», «Объединить … коммитов с веткой … из …», «Изменений нет.», «уже содержит все коммиты из», кнопка «Создать Pull Request»;
- меню «Ветка»: «Перенести коммиты текущей ветки…»; заголовок окна «Объединить коммиты и влить в …», для обычного объединения «Влить в …»; окно переноса коммитов: «Перенести коммиты …» и пункт «Перенести коммиты»;
- окно «Создать ветку»: кнопка «Создать ветку», подпись «Создать ветку на основе…»; если основа не выбирается, текст «Новая ветка будет создана на основе текущей выбранной ветки…» и «ветка по умолчанию для этого репозитория»; имена веток не переводятся;
- окно «Добавить локальный репозиторий»: кнопка «Добавить репозиторий»;
- меню рабочих деревьев: «Текущее рабочее дерево», «Новое рабочее дерево», «Основное рабочее дерево»; имя папки и ветка не переводятся;
- отложенные изменения: заголовок «Отложенные изменения», кнопка «Вернуть»;
- параметры репозитория: «Удалённый», «Игнорируемые файлы», «Настройки Git», «Адрес основного удалённого репозитория»;
- окно «Добавить рабочее дерево»: «Имя рабочего дерева», «Имя ветки», кнопка «Создать рабочее дерево»;
- окно «Открыть с помощью…»: «Выберите редактор», кнопка «Открыть»;
- настройки Git репозитория: «Для этого репозитория», «Использовать глобальные настройки Git», «Использовать локальные настройки Git»;
- игнорируемые файлы: пояснение про `.gitignore` и ссылка «Подробнее о файлах .gitignore»;
- окно автора коммита: «Коммит от имени …», «Электронная почта», «Глобальные настройки Git можно изменить в параметрах Git.», «Адрес почты только для этого репозитория можно задать в параметрах репозитория.», кнопка «Открыть настройки Git»; имя и адрес почты не переводятся;
- подтверждение перед отменой коммита в параметрах: «Отменой коммита»; команда меню «Отменить коммит…» остаётся в форме действия;
- между сборками отличаются только номер версии и служебный SHA в `main.js`, поэтому контрольные суммы у каждой сборки свои;
- текст ошибки `Unable to switch branches…` оставлен английским;
- установщик выбирает более новую из найденных папок `app-3.6.10` и `app-3.6.11` и сверяет SHA-256 именно этой сборки.

Проверка 1.4.2 относилась только к GitHub Desktop 3.6.10.

Патч не изменяет пользовательские репозитории, учётную запись GitHub, пароли, настройки Git или файлы проектов.
