# Проверка русификатора 1.4.6

Дата проверки: 12 ноября 2026 года.

Окружение:

- GitHub Desktop 3.6.10 и 3.6.11;
- Windows PowerShell 5.1.

Результаты сборки:

- подготовлено 568 операций перевода;
- одни и те же 792 замены проходят по `main.js` и `renderer.js` обеих сборок;
- поле краткого текста коммита подписано «Заголовок коммита (обязательно)»; второе поле по-прежнему «Описание»;
- карточка опубликованной ветки: «Просмотр Pull Request из текущей ветки» и «Создание Pull Request из текущей ветки»; кнопки «Просмотреть Pull Request» и «Создать Pull Request»;
- заголовок списка веток «Recent branches» переведён как «Недавние ветки»;
- окно «О программе GitHub Desktop»: версия, проверка обновлений, бета-канал, условия и лицензия;
- пункт меню «Вид»: «Скрыть фильтр изменений» и «Показать фильтр изменений»;
- в дополнительных параметрах пояснение к Git Credential Manager начинается с «Используйте»;
- во внешнем виде: «Прочее», «Ширина табуляции (симв.)», «Всегда показывать список рабочих деревьев»;
- кнопка соавторов: «Добавить соавторов» и «Убрать соавторов»;
- меню параметров коммита: «Пропустить хуки коммита», «Добавить строку Signed-off-by», «Разрешить пустой коммит»;
- окно создания репозитория: «Создать новый репозиторий», «имя репозитория», «путь к репозиторию», «Создать файл README», «Файл .gitignore», «Лицензия», кнопка «Создать репозиторий»; пункт «None» в обоих списках показывается как «Нет», сами шаблоны .gitignore и названия лицензий остаются оригинальными;
- между сборками отличаются только номер версии и служебный SHA в `main.js`, поэтому контрольные суммы у каждой сборки свои;
- текст ошибки `Unable to switch branches…` оставлен английским;
- установщик выбирает более новую из найденных папок `app-3.6.10` и `app-3.6.11` и сверяет SHA-256 именно этой сборки.

Проверка 1.4.2 относилась только к GitHub Desktop 3.6.10.

Патч не изменяет пользовательские репозитории, учётную запись GitHub, пароли, настройки Git или файлы проектов.
